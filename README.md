# Mappa zone ATC · BU Nord

Strumento per disegnare le zone ATC sui comuni del Nord Italia (confini ISTAT 2026, SAU e colture dal Censimento agricoltura ISTAT 2020).

- Si apre dal browser, senza account: https://camit1787.github.io/zone-atc/
- Il lavoro di ognuno resta nel suo browser: per salvarlo o mandarlo usare **Backup** o **Invia come file**.
- La versione è scritta in alto a sinistra sulla mappa (ora: Versione 3.1).
